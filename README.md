# SimpleText Editor
A lightweight, distraction-free, and **completely offline** word processor designed for fast writing, clean formatting, and total data privacy. Inspired by the classic simplicity of Microsoft Word, SimpleText provides all the essential document creation tools without the clutter, cloud requirements, or heavy resource usage.
## ✨ Key Features
 * **100% Offline Capability:** No internet connection required. Your files stay strictly on your local machine, ensuring complete privacy and security.
 * **Familiar Ribbon Interface:** Clean, intuitive layout featuring a top toolbar for quick access to styling, alignment, and formatting tools.
 * **Essential Formatting Options:**
   * **Typography:** Choose from system fonts, adjust sizes, and apply **Bold**, *Italic*, <u>Underline</u>, and Strikethrough.
   * **Paragraph Control:** Left, center, right alignment, and adjustable line spacing.
   * **Lists:** Easily create bulleted and numbered lists.
 * **Multiple File Formats:** Open, edit, and save documents in standard formats including .docx, .txt, and .rtf.
 * **Word & Character Count:** Real-time tracking displayed discreetly at the bottom status bar.
 * **Light & Dark Modes:** Switch seamlessly between themes to reduce eye strain during late-night writing sessions.
## 🚀 Getting Started
### Prerequisites
 * Windows 10/11, macOS, or Linux
 * No external dependencies or runtime environments needed (standalone executable).
### Installation
 1. Head over to the Releases Page to download the latest version for your operating system.
 2. Extract the downloaded zip file to your preferred folder.
 3. Run SimpleText.exe (Windows) or open the app from your Applications folder (macOS/Linux).
## ⌨️ Useful Keyboard Shortcuts
| Action | Windows / Linux | macOS |
|---|---|---|
| **New Document** | Ctrl + N | Cmd + N |
| **Open File** | Ctrl + O | Cmd + O |
| **Save File** | Ctrl + S | Cmd + S |
| **Find Text** | Ctrl + F | Cmd + F |
| **Undo** | Ctrl + Z | Cmd + Z |
| **Redo** | Ctrl + Y | Cmd + Shift + Z |
